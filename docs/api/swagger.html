Testing APIs: Select the appropriate server from the dropdown below for the endpoint you want to test. PocketBase API uses /collections/… paths with PocketBase server. OSRM, Nominatim, Simulation and Voice each have their own server entries. Only services with CORS enabled can be tested directly from the browser.

Auth flow:
  1. Select PocketBase API server
  2. Call POST /collections/users/auth-with-password with email/password
  3. Copy the returned token value
  4. Click Authorize (top right) and paste the token as Bearer <token>
